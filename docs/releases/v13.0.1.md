## Independent camera rendering, with LIBERO preview fixes

- The viewer defaults to standard PBR; MuJoCo cameras default to classic model lighting/materials. Both share one physics state, and no appearance arguments are required.
- Named `MujocoAppearance.Standard` and `.Classic` constants provide typed optional overrides across RGB-D, PNG/canvas, streams and live viewports.
- Corrected native cube textures that repeat one square image across all six faces. This fixes missing LIBERO camera panes and repeated expensive preview failures.
- Removed per-pixel temporary allocations in classic texture conversion. Failed representation builds are cached, and failed streams stop retrying until their configuration or model changes.
- Official MuJoCo4.0.1 bindings, physics and controller guards are unchanged. Rendering alternatives are cached and viewer state is restored on errors and before async readback yields.
- Migration from12.x: use `appearance: MujocoAppearance.Standard` for previous PBR/sRGB camera output. Standard remains the viewer default. Infinite planes retain the existing finite visualization proxy; native infinite-horizon, shadow and reflection parity are excluded.

Validation:29 runtime tests, type checks and builds;14 browser GPU checks; LIBERO's two default640×480 RGB-D cameras verified with unchanged standard viewer pixels and physics. Camera panes and orbit interaction were also checked through native computer use.
